# 平台化收口计划（AI 只能用平台内的工具）

> 日期：2026-09-17
> 目标：把 shipin-platform 从"AI 自由操作底层 API 的脚本平台"收敛为
> "**AI 只能调用受控平台接口**、底层能力一律内部化"的平台级别形态。
> 原则：不删任何功能，只封入口、收权限、归档残余；一切以回归测试（265 条基线）为门槛。
