# 审查升级轮 41（2026-09-22）：六审体验性残留两修

## 41a：spec 与 reason 双空 → IDENTITY_UNVERIFIED（不再直接 critical）

轮 35c 把「spec 空」向 critical 兜底（防"换人在措辞不利时静默降级"),
六审指出其反面：模型**既不给不一致点也不解释**（`same:false,
spec:"", reason:""`）时，最没信息量的答案受了最重的罚——一次字段
漂移/打太极就禁发正常片。

**修**：spec 与 reason 双空 → `IDENTITY_UNVERIFIED` **suggestion**
（"身份存疑但证据不足，建议人工复核或重审"）；spec 空但 reason 有
实质内容（"脸部完全不同"）仍走 critical 兜底——fail-safe 方向不被
削弱。

就在，改的是 issue 主句）。
