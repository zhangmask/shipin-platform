# 审查升级轮 18（2026-09-21）：人物镜代词覆盖（她/她们）

## 缺口：主体写「她」时两个通道全静默跳过

`_PERSON_HINTS` 靠「主角/女子/咖啡师…」等名词识别人物镜。LLM 写的
分镜主体一旦用代词且不带「主角」字样——「她坐在窗边喝咖啡」「她在
深夜街头独行」——跨镜配对（`_person_pair`）与镜内通道
（`_is_person_shot`）双双静默跳过：那个镜头的换人/换装根本没人审。
轮 16 补过男女复合词与职业词，遗漏了最常用的代词形态。

## 改动（hard_gates.py，一行词表 + 两条测试）

`_PERSON_HINTS` 补 `"她", "她们"`：

- 「她」在中文里无商品词包含（女包/男装这类都不含她）→ 单字入表
  安全，且正好堵住「他」不能入表的原因——「**其他**」含他，
  「其他装饰特写」会被误当人物镜（有单测 `test_ta_word_not_person`
  固定这个边界）。
- 角色词表 `_PERSON_ROLES` 不加代词：代词是泛称，不构成
  「不同角色」判据（与「主角」同等对待）。

## 测试（TestIdentityGate，17/17）

- `test_pronoun_subject_paired`：「她坐在窗边喝咖啡」vs「她站在
  街角」→ 跨镜 checked=1、镜内 intra_checked=2；
- `test_ta_word_not_person`：「其他装饰特写」vs「其他陈设」→ 两个
  通道都不查（固定「他」不入表的理由）。
