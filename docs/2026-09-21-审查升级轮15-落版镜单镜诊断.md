# 审查升级轮 15（2026-09-21）：落版镜单镜诊断（outro_card 补审）

## 缺口：品牌落版镜从未进入单镜诊断

`outro_card` 镜头在 generate 阶段被显式跳过（落版卡留给 assemble 的
kenburns 生成）——于是轮 12 的单镜诊断对它天然失效；而轮 13 的入拼
复审也只覆盖 master 补料 part，kenburns 产物同时是 clip 与 master
（长度按 窗口+td 生成，不会触发补料）→ **落版镜是全片唯一没有单镜
诊断的镜头**。它恰是品牌落版的最关键镜头：终审的 BRAND_MISSING 只兜
「品牌有没有出现」，不兜「落版画面是否符合分镜」（错帧、错尺寸、
渲染残缺一律看不见）。

## 改动（pipeline_runner.py，assemble 的 kenburns 分支）

kenburns 产物生成后补一次 `vlm_review_shot(kb_output, last_shot)`
（帧点/判定与轮 12 完全一致），结果并入 `shots_review.json`——走轮 12
既有的合并通道，critical 自动并入终审强制 fix。异常时记 error 条目，
不阻断 assemble（终审另有 VLM 通看兜底）。

## 真实验证（coffee-v7 S09，kenburns + 单镜诊断）

```
kenburns ok: True | output: .../S09_clip.mp4
落版镜单镜诊断: pass | frames: 4
```

S09 首帧即分镜预期的 slogan 落版帧，诊断通过（通道价值在反向：
引用错帧/渲染残缺时该镜现在会被 SHOT_STORY_MISMATCH 钉住）。
