# 审查升级轮 10：kind 缺失时的语义兜底 + 真机重验（2026-09-21）

## 背景：模型 kind 标注跨会话不稳定

轮 9 的剪辑豁免依赖 VLM 在 `breaks[]` 里显式打 `kind="boundary"`。coffee-v7
真机跑了两轮：

- v9 轮：6 条 break 全带 kind（5 条 `boundary` + 1 条 `intra` 真缺陷）；
- 相邻轮（9.1，未提交）：同一批断帧**全部不带 kind** → 走

  `kind = str(b.get("kind") or "intra")` 兜底 → 5 条合法换镜全部回落成
  `intra`，被当成 critical 误拦。

即：加不加 kind 是模型的会话级随机，不是内容语义。上一轮只修了
「kind=boundary 时给豁免」，没覆盖"模型整个不标 kind"的场景。

## 修复：`_is_boundary_transition` 语义兜底（hard_gates.py）

原内联条件 `kind == "boundary" and t 在边界±_BOUNDARY_MARGIN` 提为独立
判定函数，追加第三档：

1. **t 必须在真实镜头边界 ±2.0s 内**（采样帧与剪辑瞬间的偏移 0.45~1.6s，
   跨镜采样对帧最远 ~1.6s；没有边界支持的一律不豁免）。
2. `kind == "boundary"` → 直接豁免。
3. kind 缺失/标 `intra` 时：`desc` 必须**含换镜语义词**（换镜/转场/镜头
   切换/跨镜头/切换/切至…），且**不含告警词**（错位/异常/疑似/崩坏/变形/
   漂移/闪白/撕裂…）。

告警词优先于语义词——真实缺陷的描述（如 "疑似画面内容错位"）同时含
"切换" 和 "错位"，必须仍拦。这是与 29.18s 真缺陷案例（v9）的唯一区分量。

### 配置

```
_BOUNDARY_MARGIN = 2.0
_BOUNDARY_SWITCH_WORDS = ("切换", "换镜", "转场", "镜头交替", "切至", "镜头切换", "跨镜头", "正常交接", "过渡")
_BOUNDARY_ALARM_WORDS = ("错位", "异常", "疑似", "崩坏", "花屏", "变形", "漂移", "鬼影", "残影", "撕裂", "闪烁", "闪白", "闪帧", "雪花", "污染", "缺损", "丢失")
```

### 测试（TestBoundaryBreakGate 新增 3 例，全绿 48/48）

- 无 kind + desc 含"跨镜头正常交接" + t 在边界内 → 豁免进 boundary_transitions；
- 无 kind + desc 含"切换…疑似画面内容错位"（29.18 型）→ 仍 critical；
- 无 kind + 换镜语义齐全但 t 远离边界 → 仍 critical。

## 真机重跑（coffee-v7 → final_review_v10.json）

重跑 `vlm_review_final(final.mp4, frames_count=30)` —— 与 v9 完全相同的输入：

  5 + 身份 4）；同一真机的两次独立跑，结论等价（模型换轮把 29.18 型缺陷
  换了个描述对象重新打分）。
- 模型本轮 5 条 break 又全部给了 kind（4.03 标 `intra`、其余 4 条标
  `boundary`）——kind 缺失兜底未触发，但证明协议本身稳定。
- 4 条合法换镜（7.21/15.09/16.64/21.57）→ `boundary_transitions`，不再
  误报 critical ✓。
- 4.03 `intra` 按设计保留：该帧处于 S01→S02 交界（|4.03-3.2|=0.83 ≤

- 记录到模型轮次间随机性：v9 是 29.18s 品牌卡疑似错位，v10 换成 4.03s
  换装——门禁不能依赖"这轮模型恰好把 kind 标对"，语义兜底就是为此上马。

## 结论

- 合法换镜全部放行，不再误报 critical；
- 真缺陷（跨镜人物被更换/服装突变）保持 critical，verdict fix 不变；
