# 轮45：generate 失败诊断缺口——「3 次生成未成功」不再无迹可寻

日期：2026-09-23。起点：轮44 收尾时 E2E 第 6 次复跑（`e2e_h44e.log`，43 分钟）
以 `S08 3 次生成未成功——旧素材/过期 qc 状态不得复用` 失败，且**reason 里
没有任何细节**（对比第 5 次失败带 `429 Client Error`）。

## 问题定位（诊断考古，非猜测）

1. `generate_video_agnes`（`generation/generate_assets.py:188`）只有两种出口：
   抛异常（`raise_for_status` / `RuntimeError`）或返回 dict——**永不返回
   None**。因此 E2E 现场「reason 无 error」= 生成成功、`qc_clip` 判 fix 三次。
2. `pipeline_runner.py` 的 attempt 记录只写 `{"attempt", "qc", "cuts"}`，
   `qc["findings"]` 全文丢弃；reason 只拼接网络异常 error。于是
   **「生成成功但 QC 判 fix」这一整类失败（REF_MISMATCH 参考图漂移 /
   INTERNAL_CUTS 镜内切镜 / MORPH / TRANSIENT_FLASH）在 reason 里零信息**——
   S08（slogan 落版镜）到底是哪条 critical 三连败，永远查不到。
3. 排除了两个候选根因（均有实测证据，非推测）：
   - 静态卡被 motion 门误杀：实测 `fade=t=in` logo 近似片段
     motion_energy=12.587、verdict=ok（BLACK_FRAMES_EDGE 仅 warning）——否。
   - VLM 协议失败伪装 critical：`clip_qc.py:456-487` 的 `available=False`
     只进 `note`，分类学本来正确——否。
   真实最大候选：变体改了 style_anchor 后重生 clip 与基准项目参考图的
   dHash 距离超限（REF_MISMATCH）——但**没有诊断信息时这只能是猜测**，
     这正是本轮要修的东西。

## 修复（`orchestration/pipeline_runner.py`）

1. attempts 记录 findings 全文：每条含 `severity/code/message`（截断 200
   字符），另存 `vlm_note`（VLM 不可用原因）。
2. 失败 reason 两级组织：网络异常优先（更可操作），否则
   `QC: <CODE>#<attempt>/...`（去重、上限 4 条）——attempt 号保留，
   「第 2 次换提示词后仍败」与「三次同因」一眼可分。
3. `r is None`（生成器静默返回空）显式记
   `"生成器返回空结果(无异常)"`——该 attempt 不再无迹可寻（防御性：
   agnes 当前不可达，但调用点不保证永远只有这一个生成器）。

## 测试（`tests/test_pipeline_intent.py::TestGenerateFailureDiagnosis`，4 例）

- `test_qc_critical_code_surfaces_in_reason`：fake qc 三次判 fix →
  reason 含 `QC: REF_MISMATCH#1` 且三 attempt 同码不同号齐全；
  attempts 带 findings 全文（critical + suggestion + message）。
- `test_silent_none_return_is_recorded`：生成器返回 None → 三次 attempt
  均留痕 + reason 可读。
- `test_network_error_takes_priority_over_findings`：429 与 QC 败并存时
  reason 以 429 为主，findings 仍完整在 attempts 里可查。
- `test_real_qc_static_clip_diagnosed`：**不用 fake qc**——真 `-loop 1`
  静态卡走真 `qc_clip`（只 stub VLM 两网络调用），reason 出现
  `STATIC_SLIDESHOW#1`；同时断言协议失败不升级：`REF_VLM_MISMATCH` /
  `MORPH_DETECTED` 不得出现，`vlm_note` 进 note 可解释。

## 回归与遗留

- 非 E2E 全套绿（592 → 596 基线 + 本轮 4）。
- E2E 仍待 AGNES 429 窗口：下次复跑时若 S08 再败，reason 会直接给出
  critical 编码——是 gate 正确拦截漂移（预期行为、E2E 对真实 API 天然
  抖动），还是参考图策略需要随变体重派生（产品层问题），届时可判。
