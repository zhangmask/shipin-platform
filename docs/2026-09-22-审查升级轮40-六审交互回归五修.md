# 审查升级轮 40（2026-09-22）：六审交互回归五修（含一处自修复 CRITICAL）

## 40a：尾段覆盖把「未审洞」换成「凡有尾段必拦」（CRITICAL，自修复回归）

轮 38 的尾部覆盖给每个尾段帧唯一 tag「尾部+X.XXs」→ 覆盖计数里每条
cnt 恒 1 → `COVERAGE_THIN` 必触 → **任何尾段 >0.5s 的成片终审恒判
fix，无法交付**。轮 38 自测只断言 coverage key 存在、没断言 verdict，
564 全绿看不见。六审实锤复现（6.8s 视频 + 3×2s 分镜 → COVERAGE_THIN
→ fix）。

**修**：尾段帧统一固定 tag「尾部」（聚合计数）；THIN 判定从硬编码
`cnt < 2` 改为**按计划帧数**（`cnt < planned_n`，尾段计划 1 帧即算
足额；分镜的 THIN 也顺带按真实计划判——8s 镜计划 5 帧只到 4 帧会报，
旧逻辑不报）。

## 40b：末镜起点边界的豁免窗按左邻镜定尺 → 短末镜被吞

`_is_boundary_transition` 原来对每个边界取「到最近邻边界的距离”定尺：
末镜起点边界的最近邻是**左镜**（倒数第二镜时长）——短末镜+长前镜时
eff=2.0s 吞掉整个短末镜，尾段帧也在右窗内（六审 #2 实锤：
shots=[9,8,1.2]，尾帧 18.5/18.9 标 kind=boundary 全被豁免）。

**修**：单侧窗口——每个边界按左右两侧分别定尺
`eff_side = min(margin, 1.6s 保底, 该侧相邻镜长)`；`_shot_boundaries`
新增 `with_total=True` 追加 Σ（片尾锚点），两端外侧距离为 0（片头前/
片尾后没有镜，无所谓采样偏移）。Σ 只进豁免调用点——确定性滤波
（内部切/瞬变/黑帧的"临近边界=合法转场"）保持旧语义（Σ 不是画面
真实剪辑点，尤其是还有尾段时），否则临近片尾的闪帧会被当合法过渡
放行（该回归被现有测试当场抓住）。
