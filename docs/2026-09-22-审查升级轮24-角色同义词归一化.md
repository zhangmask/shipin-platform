# 审查升级轮 24（2026-09-22）：身份配对角色同义词归一化

## 缺口：同义词角色被误判“不同角色”而整对跳过

轮 16 的 `_person_pair` 用「规范角色无交集 → 不同角色 → 跳过」避免把
顾客 vs 店员的合理切换误判为换人。但角色词是**字面**比较：
「白领在办公室加班」vs「上班族走进地铁」本是同一类人，字面不同 →
判为不同角色 → 整对跳过 → 这两个镜之间换人从未被审。同类问题：
女人/女生、女子/女性、消费者/顾客、用户/顾客、孩子/少年。

## 改动（hard_gates.py）

- `_ROLE_SYNONYMS` 同义词表 + `_roles_of(subject)`：先把角色词归一到
  规范角色（白领→上班族、女人/女子/女孩/女生→女性、消费者/用户→
  顾客、孩子/少年→儿童…）再比交集；
- `_person_pair` 改调 `_roles_of`；顾客 vs 店员这类**真不同角色**仍
  跳过（语义不变）。

## 测试（TestIdentityGate，19/19）

新增 2 例：白领 vs 上班族 → 归一后同角色，checked=1；女人 vs 女生
→ checked=1。咖啡师 vs 顾客 旧用例保持 skipped。
