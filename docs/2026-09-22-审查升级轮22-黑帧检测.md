# 审查升级轮 22（2026-09-22）：黑帧检测（blackdetect，clip + 终审双层）

## 缺口：整段黑屏没有一门在看

审查链的画面异常覆盖此前是：闪帧有 `transient_spikes`（逐帧亮度
跳变）、冻结有 `motion_energy`（运动能量下限）、崩坏有 VLM
（anomaly/morph）——**「整段变黑」是空洞**：运动能量取平均，一段
1s 黑屏夹在运动画面里可能仍高于下限；VLM 抽样可能只抽到黑帧两侧；
而黑屏是明确的交付级画面异常（生成失败/转场穿帧/渲染残帧），正对
用户第 1 问「有没有核查异常/崩溃」。

## 改动（clip_qc.py + hard_gates.py，纯确定性零成本）

- `clip_qc.black_spans(video, min_dur=0.4, pix_th=0.10)`：ffmpeg
  原生 blackdetect，解析 `black_start/black_end/black_duration`，
  never raises；
- **clip 层**（qc_clip，每镜）：镜内黑段 → critical `BLACK_FRAMES`
  （生产级：直接触发该镜重生成）；贴边 ≤0.25s（生成淡入淡出残留）
  → warning `BLACK_FRAMES_EDGE`；
- **终审层**（vlm_review_final 确定性段）：黑段距镜头边界 >1.5s
  （排除叠化拼接的正常压黑过渡）且不在片头片尾 0.3s 内 →
  critical `FINAL_BLACK_FRAMES`（带时间段列表）。

## 真实验证（coffee-v7）

`final.mp4` black_spans=[]；10 个 `SXX_clip.mp4` 全部无黑段——
健康物料零误报。检出方向由 5 条单测的合成黑段固定。

## 测试（TestBlackFrameGate，5/5）

- clip 镜内黑段（3.6~4.4s）→ BLACK_FRAMES critical；
- clip 贴边黑段（0~0.5s）→ 仅 BLACK_FRAMES_EDGE warning；
- 干净 testsrc2 clip → 无黑帧 finding；
- 终审黑段距边界 >1.5s → FINAL_BLACK_FRAMES critical；
- 终审黑段贴边界 ±1.5s（叠化压黑）→ 豁免不拦。
