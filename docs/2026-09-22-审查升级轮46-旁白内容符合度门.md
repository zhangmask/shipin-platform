# 轮46：旁白**内容**符合度门（ASR）——解除「ASR 待定」挂账决策项

日期：2026-09-23。承接轮45 诊断修复后的 E2E 复跑窗口期。

## 背景：存在性门的天花板

轮14 的 `check_narration_presence` 是确定性门（silencedetect），只能
证明「旁白窗口里有声」。它回答不了用户三问中的第二问（审核到底
符不符合剧本）的音频侧：TTS 串轨/换轨/文本漂移时画面照演、声轨
照响，**说的根本不是剧本这一句**——与轮42 修的「新指纹盖旧音频」
是同一病族的终片层残留。此前唯一兜底是终审 VLM（16 帧抽样看画
面），音频内容从未被核过。

whisper 权重本地就位（~/.cache/whisper 有 base/tiny，whisper
20250625）+ reference 流水线已验证 ASR 通路，「ASR 内容核查待定」
的挂账决策项解除。

## 实现（`review/hard_gates.py`）

`check_narration_content(video, shots, transcriber=None)`：

- 每镜窗口（narr_at/audio_start_sec + tts_sec/duration，与存在性门
  同一口径，共用新抽出的 `_shot_voice_text`）→ WhisperService(zh)
  整片转写一次 → 段文本与窗口重叠匹配 → 与剧本文本算相似度
  （`difflib.SequenceMatcher`，归一化后）；
- 分级：`< _NARR_CONTENT_CRIT(0.45)` critical NARRATION_MISMATCH；
  `< _NARR_CONTENT_WARN(0.65)` warning NARRATION_DRIFT；
- **分类学**：协议失败（无 whisper/模型加载/转写异常，含注入后端
  抛错）→ `verdict="skip"` + `available=False` + 零 findings——
  不伪造判定、不冒充覆盖缺口；窗口内无语音 → 跳过（存在性门的
  地盘）只进 stats；纯画面镜整片跳过（不白付 ASR 成本）；
- assemble 接线：结果并入 `narration_check.json`（content 子键 +
  findings 进顶层），既有合并通道（narration_check → 终审 fv）
  自动生效，内容 critical 强制终审 fix。

## 真 ASR 校准（不是纸上阈值）

用项目自己的 edge-tts（biz_female 角色）合成中文、whisper base
(CPU) 真转写，双向验证：

| 场景 | ASR 听到 | 剧本预期 | sim | 判定 |
|---|---|---|---|---|
| 一致 | 夜晚的星空很亮,咖啡的香氣很濃。 | 夜晚的星空很亮，咖啡的香气很浓 | 0.857 | ok |
| 错配 | 這款茶包清香蛋牙 | 这款咖啡香气浓郁 | 0.375 | critical |

**校准中发现并修复的真问题**：whisper(zh) 对简体剧本吐**繁体**
转写（香氣很濃 vs 香气很浓）——6 字短句整句繁简差异可把相似度压
到 ~0.5，稳定误报 critical。修法：`_norm_text` 加 zhconv 繁→简
归一（zhconv 缺失时优雅降级不崩）。同句复测 sim 1.0。

## 测试（`TestNarrationContent`，10 例）

一致通过 / 错配 critical（message 带剧本原文）/ 中段改写漂移
warning（**注意：吞尾半是前缀匹配，SequenceMatcher 会给 0.77，

协议失败 skip（注入后端 + 默认后端 monkeypatch 两条路）/
纯画面镜不调 ASR / 窗口无语音只记账 / 台词镜同样查。

## 遗留与边界（如实记载）

- 阈值 0.45/0.65 基于 base 模型 + edge-tts 清晰中文 TTS 的 2 个
  真实样本 + SequenceMatcher 特性标定；换 ASR 后端/音色/方言后
  建议复校（SHIPIN_ASR_MODEL 可换模型档）。
- ASR 成本：整片一次转写（base/CPU，60s 素材实测秒级），assemble
  既有 VLM 审片量级内可接受。
- 吞字型漂移（ASR 漏听半句）可能落在 warning 带——设计如此：
  内容门是"说的对不对"，"说得全不全"由存在性门的 NARRATION_THIN
  与人工复核 warning 承接。
