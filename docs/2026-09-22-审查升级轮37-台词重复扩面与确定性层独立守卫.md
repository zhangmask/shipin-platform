# 审查升级轮 37（2026-09-22）：台词重复判定扩面 + 确定性层独立守卫（五审收尾）

## 37a：台词-旁白重复只查首子句 → 分句 + 整句包含

旧规则 `text.split("，")[0] in narration`：重复信息只要不在首子句就
完全逃逸（配音仍念两遍）。改为三重判定（归一化后）：

1. 台词的**任一分句**（按中英文标点切分，归一化 ≥4 字避开"好的"类
   trivial 匹配）是旁白的子串；
2. 或整句互相包含（台词被旁白原样吸收，或反之）。

边界（写进测试注释）：**换字复述的语义级重复**（如台词"源自匠心
烘焙" vs 旁白"都经匠心烘焙"——共享概念但字面不同）字面层抓不到，
属 LLM 审片 rubric 的职责，本轮明确到此为止。

## 37b：确定性层从"一个 try"拆成四个独立守卫

终审确定性层原本把五大检查（硬切/节奏、音频+运动、亮度瞬变、黑帧）
包在同一个 try 里：任一处探测异常（ffprobe 字段 `"N/A"` 转 float、
黑帧解析炸…）会把**全部**确定性检查降级成一条
`DETERMINISTIC_PASS_ERROR` suggestion——单点失败 = 整体放弃确定性
防线（五审补充项）。

改为 `_det_guard(name, fn)` 逐检查独立 try/finally：单点失败只废那
一个检查、错误信息指名失败项（`确定性检查[audio_motion]失败: …`），
其余检查照跑。

## 测试（engine 55/55、hardening 108/108）

- 台词第二分句与旁白逐字重复 → 报（旧行为漏）；
- 整句被旁白吸收 → 报；信息互补 → 不误报；
- `motion_energy` 炸（monkeypatch）→ 黑帧检查幸存
  （FINAL_BLACK_FRAMES 照出），DETERMINISTIC_PASS_ERROR 只报
  `[audio_motion]` 一项。
