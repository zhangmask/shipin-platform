# 轮50：画布车道诚信（九审 P1-2/P1-4 收口）——TTS 不串音频 + 花钱必入账 + 预算熔断

日期：2026-09-23。第 9 轮审计画布车道（ComfyUI 式节点图）两个 P1 的修复。

## P1-2 `_exec_tts` 输出解析错乱（graph/engine.py）

- 病：`synthesize_segments_sync([seg])` 返回值整个丢弃；随后先找
  永远不存在的 `{node_id}.mp3`，再
  `sorted(art_dir.glob(f"{_safe(node['id'])}*"))[0]`——**无 `_` 分隔
  的前缀 glob + 字典序首个**。三类故障形态：
  a) 前缀共享：`'n10_x.mp3' < 'n1_y.mp3'`（'0' 0x30 < '_' 0x5F）→
     删除节点后补位产生的 n1/n10 共存（或客户端 PUT 任意前缀 id）
     让节点 n1 拿到 n10 的台词音频；
  b) 改文本重跑：旧 uuid 文件仍在，字典序可能选中上一轮旧口播；
  c) 合成失败（edge-tts timeout）：段上挂 error/output_path 空，但
     cands 非空 → **返回旧音频且节点状态 ok**。
  三类错都顺 assemble 流出，而画布车道没有任何旁白/声画一致性门。
  这正是 pipeline 车道轮31/轮26 修过的两类 bug，画布车道原样存在。
- 修：以 synthesize 返回的 `output_path` 为**权威值**；`seg.error`
  非空或文件不存在 → 显式 `RuntimeError`（节点状态 failed）。glob
  整个废掉——不再依赖命名约定与字典序。
- 测试：n10 先落盘再跑 n1（旧实现此时必串）、失败不留旧轨（状态
  failed 且错误可见）。两条**旧代码下必挂**。

## P1-4 画布车道零记账、零预算（graph/engine.py）

- 病：`_exec_image_gen`/`_exec_video_gen`/`_exec_tts` 直连付费
  供应商（agnes-image/video、edge-tts），但全车道（engine +
  api_graph）无一处 `record_cost`、无 `_enforce_budget`，
  `data/graphs` 也不在 `global_cost_summary` 扫描范围。违反平台
  不变量「每次真实生成都登记」；同一把 key 在 pipeline 车道被 422、
  画布车道可无限花钱且 showback 零可见。
- 修：
  - `_graph_cost_pid(gid) = f"graph-{gid}"`：画布成本落在
    `data/projects/graph-<gid>/cost.json`——global_cost_summary 扫
    data/projects/* 自然纳入，预算文件同约定可配；
  - 三个花钱执行器成功后入账（image 按次、video 按秒——与 costing
    计价单位一致、tts 按次；pil 占位不花钱不记）；
  - `_budget_blocked(graph)`：全局月度闸 + 本图预算文件双判据，
    账本损坏视为超限（不按空账放行）；
  - `run_node` 循环内对 `_SPEND_NODE_TYPES` 执行前复查——run_all
    逐节点走同一路径，全覆盖。熔断时节点状态 `blocked_by_budget`，
    RuntimeError 带原因。
- 测试：image_gen 入账落盘（kind/units 正确）；超预算后再跑被
    `预算熔断` 且状态 blocked_by_budget。
