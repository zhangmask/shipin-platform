# 审查升级轮 17（2026-09-21）：剧本钉外观时换装升 critical

## 由来：换装是"风格选择"还是"违反剧本"

跨镜身份门里 COSTUME_SWAP（仅服装不一致、脸/发一致）一直是 warning
——默认换装是导演自由。但 coffee-v7 的剧本把主角外观**钉死**了：
actor_anchor 明写「黑色长直发披肩、米白色针织开衫、深灰色围巾」，
S01 主体逐字带这套描述，而成片里有三种造型（米白开衫→深色外套→
灰蓝衬衫→卷发毛衣）。剧本写了造型，换装就是**违反剧本**，与用户
第 3 问「关键人物有没有被改变」直接冲突—— warning 级不够。

## 改动（hard_gates.py + pipeline_runner.py）

- `_look_pinned(shots, actor_anchor)`：anchor 或任一镜主体含服装/
  发型式样词（衫/外套/围巾/裙/西装/制服/毛衣/裤/帽/鞋/眼镜/发型/
  长发/短发/直发/卷发/披肩/马尾/胡须…）即认为剧本钉了外观。
  刻意不收单字「镜」「装」——「镜头」「装饰」会误命中。
- `_identity_finding(..., pinned_look)`：纯服装层不一致
  （spec 不含脸/发）且 pinned → severity 升 critical，message 附
  「剧本已钉死人物造型,换装即违反剧本」。
- `_identity_gate(..., pinned_look=False)` 透传；`vlm_review_final`
  从 ctx 的 `actor_anchor` + 各镜主体自动判定。
- assemble 的终审 ctx 补 `actor_anchor`（与 text 阶段同一解析式：
  brief.actor_anchor/hero_anchor/character）。

## 真实验证（coffee-v7 → final_review_v17.json）

```
 - critical IDENTITY_SWITCH(cross) S01→S02   脸
 - critical IDENTITY_SWITCH(cross) S05→S05b  脸/发型
 - critical COSTUME_SWAP(cross)    S05b→S06  服装  ← 轮17 升级:
     「跨镜身份已更换,禁止交付（剧本已钉死人物造型,换装即违反剧本）」
 - critical IDENTITY_SWITCH(cross) S06→S07   脸
verdict: fix；boundary_transitions 5 处合法换镜全豁免
```

## 测试（TestIdentityGate，15/15）

新增 3 例：主体写服装式样 → 纯服装 critical（message 带说明）；
泛称主体无外观词 → 维持 warning（风格自由不被误伤）；
外观只写在 actor_anchor → 同样 critical。

## 边界

- 多套造型本身是叙事设计（日夜/场合换装）且剧本**未**钉外观时，
  仍是 warning——不误伤导演自由；
- 要"允许多套造型"应在剧本层显式声明（anchor 去掉服装描述），
  门闩语义与剧本始终一致。
