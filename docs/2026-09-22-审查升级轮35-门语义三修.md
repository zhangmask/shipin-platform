# 审查升级轮 35（2026-09-22）：门语义三修（边界 margin 缩放/协议违约 fail-closed/spec 空兜底）

> 五审审计对象从管线 plumbing 转向「门本身」的语义，三条均本地复现实锤。

## 35a：边界豁免窗吞掉短镜中段（系统性漏报）

`_is_boundary_transition` 的 margin 固定 2.0s。对 ≤4s 的短镜，
bounds=[0,4] 时**任意 t 都满足 |t-b|≤2**——整镜都在豁免窗内。实测：
4s 镜 t=1.0/2.0/2.5/3.0/3.9 标 `kind=boundary` 全部返回 True
（中段崩坏静默放行，`boundary_transitions` 只计数不进 findings，运营
无感）。单镜诊断路径同病（2s clip margin 0.75 时 0.5s/1.5s 均豁免）。

**修**：`eff_margin = min(margin, max(1.6s 采样覆盖保底, 25%×相邻镜长))`。

- 4s 镜：豁免窗压到 1.6s，中段 1.6~2.4s 不再被吞；
- 2s 镜：合法边界采样（t=1.4 含换镜词）靠 1.6s 保底仍豁免（轮 10 回归
  用例保住——margin 的存在意义就是吸收「VLM 报采样秒不是剪辑瞬间」的
  0.45~1.6s 偏移，不能一刀切缩）；
- 8s 以上镜：max(1.6, 2.0)=2.0，行为不变。

## 35b：VLM 协议违约从静默放行改为 fail-closed

批次循环里 `re.search` 不中或 `json.loads` 失败时 `parsed = {}` 然后
继续——**该批零 findings、零报错**。五审指出这是可被注入利用的通道：
分镜文本（subject/scene/motion/product_info 无转义注入提示词）可指令
VLM 返回非 JSON，从而单方面关闭整批内容门。

**修**（终审与单镜诊断两处）：`parsed` 为空 → 记
`VLM_PROTOCOL_VIOLATION` critical（「该批帧未审，按未审拦截」）并
skip 该批；请求异常（重试后仍失败）同样记 critical 而非静默
continue。与 COVERAGE_GAP 同规格：**没审到不许读作审过了**。

（注入的结构性防护——字段隔离/转义/长度上限——留作后续轮次；本轮先
关掉「静默放行」这个失败模式。）

## 35c：身份判定 spec 为空时向 critical 兜底

`is_face` 只查 spec 里有没有「脸/发」。VLM 返回 `spec=""`（只说
"不是同一人"没给不一致点）时 → COSTUME_SWAP **warning**，而单镜诊断
的 warning 会被 assemble 的 critical 过滤器**直接丢弃**——"换人"在
模型措辞不利时静默降级（五审 #4）。

**修**：spec 空 → `is_face=True`（向 critical 兜底，reason 仍写进
message 供人工判）。有 spec 的行为不变（"发现身材不同"这类含"发"的
误升问题本就不是空 spec 路径）。

## 测试（TestBoundaryBreakGate/TestIdentityGate，suite 109/109）

- 4s 镜中段（t=1.8, kind=boundary）→ VLM_BREAK critical（旧行为豁免）；
- 2s 镜边缘合法采样（t=1.4 换镜词）→ 仍豁免（保底不误报）；
- VLM 返回不可解析文本 → VLM_PROTOCOL_VIOLATION critical + verdict fix；
- same=false 且 spec 空 → critical（旧行为 warning 被丢弃）。
