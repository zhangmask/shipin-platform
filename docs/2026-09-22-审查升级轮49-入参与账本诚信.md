# 轮49（九审驱动）：入参诚信与账本诚信——SRT 进位、负成本、负参数、读侧穿越

日期：2026-09-23。第 9 轮独立子智能体审计（主攻 assemble 中段/align/
costing/API 面/TTS/画布车道），本轮修复 P1×2 + P2×4 + P3 中 2 项；
画布车道三项（P1-2 串音频/P1-4 零记账零预算）留轮50 专项。

## 修复清单

### P1-1 SRT 毫秒无进位产出非法时间戳 `,1000`（pipeline_runner.py）
- 病：`_build_srt.fmt` 的 sec/ms 各自独立取整，`(t%1)*1000` 因浮点
  落在整数下方时 round 出 1000 → `00:00:20,1000`。audit 实测 20 万
  次真实形态项目模拟 **1.27% 至少一中**。两个坏结局：平台自解析
  （`_srt_ts_to_seconds`）读成 20.1s（应 21.0）→ 字幕早 ~0.9s 显示、
  验收门在错误时间点量墨迹 → **假过发货**；ffmpeg/libass 自己进位而
  verify 用错解析 → 间歇性硬失败，被误诊为渲染抖动。
- 修：total-ms 进位式（`divmod`），与 `tools/subtitle_renderer.
  _format_ts` 对齐（此前两套格式化器对同一文件给出不同答案）。
- 测试：真实命中形态复现 + 回环断言（每个时间戳正则合法、ms≤999、
  自解析值与名义值差 <2ms）。

### P1-3 负 duration → 负成本入账，预算闸被掏低（api.py + costing.py）
- 病：`POST /api/generate/agnes-video {"duration": -5}` → ffmpeg
  `-t -5` 拒绝（只 warning）仍返回 ok:True → `record_cost(units=-5)`
  落 **-$0.10** 价行 → `used > max` 判据被反向掏空，反复注入可让
  超预算项目持续放行（伪造账目方向）。裸端点无 `max(dur,2)` 钳制
  （pipeline 车道有）。
- 修（双层）：API 模型 `field_validator` 拒 duration<1、钳上限 60；
  `record_cost` 纵深钳 units 到 [0, 1e6]（调用方仍应校验，兜底不
  替代）。
- 测试：负数/零 ValidationError、超限钳 60；负 units 落账 0.0。

### P2-5 align 负参数放行「旁白越窗」（api.py + assembly.py）
- 病：`POST /api/audio/align {"min_tail": -2.0}` → needed 被压到 0，
  SPILL（needed>master_duration）失效 → 旁白 2s 落进 1s 窗仍判 ok；
  负 master_duration 配无声镜甚至产出负窗口。audit 已实跑复现。
- 修：AlignRequest validators（min_tail/max_gap ≥0.05、master_duration
  ≥0、NaN 拒绝）+ `align_narration` 内部钳制（纵深，护内部调用方）。
- 测试：三个字段负值 ValidationError；内部钳制的中和验证（直接传
  min_tail=-2.0 进 align → SPILL 恢复拦截）。

### P2-7 reference_id 读侧路径穿越（api.py）
- 病：`_reference_preloaded` 直接拼 `refs_dir/{id}.json`，
  `../projects/<pid>/storyboard` 可探测任意 JSON 存在性并回显
  brief_prefill 段——写侧（ingest name）有正则校验，读侧没有。
- 修：字符白名单 + `.` 开头拒绝 + resolve 前缀双保险（与写侧对齐）。
- 测试：traversal/含斜杠/含空格/点开头 → 422；不存在 → 404。

### P2-8 裸端点计费与熔断一致性（api.py）
- 病：a) `/api/tts/narrate` units=len(segments) 含合成失败段
  （违背 pipeline 车道轮33 的 _ok_n 口径，账目虚高）；b) narrate/
  image/agnes-video 三个裸花钱端点**无 `_enforce_budget`**——超预算
  项目走 pipeline 被 422、走裸端点照常花钱。
- 修：narrate 只计成功段；三个裸端点补预算硬闸（与 variant/retry
  车道同口径）。
- 测试：与既有 TestApiGates 共存回归（端点 422 语义未变）。

### P3-9/10 账本结构损坏静默空账 + 只读端点 500（costing.py + api.py）
- 病：`_load_rows` 只对 JSONDecodeError 抛 LedgerCorruptError，「合法
  JSON 但非 list」（dict/str）静默返 [] → 预算闸判「没花钱」放行
  （与轮43 设计意图自相矛盾）；`pipeline_report`/`pipeline_budget`/
  project detail/preflight 的 `cost_summary` 未捕获 → 账本损坏时
  只读端点 500。
- 修：`_load_rows` 结构损坏同样备份+抛；新增 `_cost_snapshot` 防崩
  包装（损坏 → `total_usd=None` + `ledger_corrupt=True` 诚实快照）；
  preflight 的 budget 项损坏时判 **不可跑**（预算无法核验 ≠ 通过）。
- 测试：dict 结构损坏抛+备份；`_cost_snapshot` 损坏标记/正常路径。

## 遗留（轮50 画布车道专项 + 其余 P3）

- **P1-2 画布 `_exec_tts` 输出解析错乱**：真实落盘
  `{node_id}_{uuid8}.mp3`，而取值先找不存在的 `{node_id}.mp3` 再
  `sorted(glob(f"{node_id}*"))[0]`——无 `_` 分隔前缀 glob + 字典序
  首个：`n10_x.mp3 < n1_y.mp3`（'0'<'_'）→ 节点 n1 拿到 n10 的音频；
  改文本重跑还可能选中旧文件；合成失败返回旧音频且状态 ok。
