# 成片「画面异常」审查：业界调研与可落地方案（2026-09-21）

> 调研范围：VQA 评测体系（VBench / EvalCrafter / T2VQA / FAST-VQA / DOVER）、大厂生成管线与 open-source 审片链（ShortGPT / MoneyPrinterTurbo / ComfyUI 生态 / NVIDIA Cosmos 系）、VLM 当画面审查器的分层做法。
> 结论先行：**业界没有"一个模型全包"的审片器**；标准做法是「确定性探测器全量把关 + 轻量模型打质量分 + VLM 只做语义类异常抽检」，与本平台现状（已有 VLM-morph / 运动能量 / 静音 / 黑帧 / 镜头复用 / 品牌文字）的架构方向一致，差距在「检测种类不全、阈值未归一、VLM 采样不规范、缺一层『画面质量 MOS』兜底」。

### B0. 统一的"轻量采帧"管线（所有 D 类指标共用）

```python
import numpy as np, subprocess, cv2, json

def video_dim(path):
    p = subprocess.run(["ffprobe","-v","error","-select_streams","v:0",
                        "-show_entries","stream=width,height","-of","csv=p=0", path],
                       capture_output=True, text=True)
    w0, h0 = (int(x) for x in p.stdout.strip().split(","))
    return w0, h0

def load_luma_series(path, width=480, fps=4):
    """返回 (N,h,w) uint8 灰度块，对整条视频均匀抽帧（scale 保纵横比）"""
    w0, h0 = video_dim(path)
    h = round(h0 * width / w0 / 2) * 2           # scale=-2 取偶向下
    cmd = ["ffmpeg","-hide_banner","-i",path,"-vf",f"fps={fps},scale={width}:{h},format=gray",
           "-f","rawvideo","-pix_fmt","gray","-"]
    raw = subprocess.run(cmd, capture_output=True).stdout
    return np.frombuffer(raw, np.uint8).reshape(-1, h, width)

def mae(a, b): return np.abs(np.array(a, np.float32) - np.array(b, np.float32)).mean()
```

### B-1 静帧 / 冻结

```python
def detect_frozen(frames, mae_thr=6/255, min_sec=1.0, fps=4):
    # frames: (N,h,w) uint8; 阈值参考：MAE<7/255 基本就是同一画面
    d = [mae(frames[i], frames[i+1]) for i in range(len(frames)-1)]
    d = np.array(d)
    frozen_blocks = []   # (start_i, end_i, sec)
    # 连续冻结 run 检测
    run, s = 0, 0
    for i, v in enumerate(d):
        if v < mae_thr: run += 1; 
        elif run: 
            if run * (1/fps) >= min_sec:  # 帧数为 n 的段 = n-1 个间隔
                if i-run > s: s = i-run
                frozen_blocks.append((s, i, (i-s)/fps)); s = i; run = 0
    return frozen_blocks
```

### B-5 频闪 / 闪烁指数

```python
def flicker_index(y):     # y: 每帧亮度均值 (0..1)
    m, mn, mx = y.mean(), y.min(), y.max()
    if mx <= mn: return 0
    return (mx - mn) / (mx + mn)          # 经典"闪烁指数"近似
def vbench_flicker(frames):              # VBench 静态场景定义
    return (255.0 - np.mean([mae(frames[i],frames[i+1]) for i in range(len(frames)-1)]))/255.0
#  判定：vbench_flicker < 0.90 且 flicker_index > 0.15 → 频闪（阈值按内容标定）
```

### B-6 噪声估计（大噪/颗粒）

```python
def estimate_noise(frame_bgr):           # 拉普拉斯法（经典 Iosifidis/Immerkær）
    gray = cv2.cvtColor(frame_bgr, cv2.COLOR_BGR2GRAY).astype(np.float32)
    lap = cv2.Laplacian(gray, cv2.CV_32F)
    # 中值算子：噪声 ≈ 1.4826 * MAD(lap)
    med = np.median(np.abs(lap - np.median(lap)))
    return 1.4826 * med / 255.
#  判定：> 5/255 怀疑大噪；> 10/255 强噪（典型大片内容均值 ~2-4/255）
```

def motion_energy(prev_gray, gray, top_pct=0.05):
    flow = cv2.calcOpticalFlowFarneback(prev_gray, gray, None, 0.5,3,15,3,5,1.2,0)
    mag = np.sqrt(flow[...,0]**2 + flow[...,1]**2)
    return mag.flatten().max_pct_mean(top_pct)          # 顶5%均值（VBench dynamic_degree 公式）
# 判定：静态过滤阈值 3.0×(scale/256)（VBench static_filter, thres + count_num=round(2×(帧数/16))）
#  抖动/背景沸腾：在"静态前景掩码"区（帧差<阈值的象素）内看 mag 的零均值高方活 -> 0.5px 落帧+3σ

## C. VLM 异常审查提示词模板（中英双语 + 结构化采样）

### C-0 采样策略（对 VLM 生效的调研结论）
- 每个镜头取 **3~8 帧**（首/中/尾 + 中间 1 处折数处），帧数越少 token 成本越低；**不要逐帧**（噪声、token 浪费）。
- 配套把 B 节的确定性判据（如“0.8s−1.5s 黑场”“运动能量骤升”）**并列给模型**——让 VLM 只做语义确认，避免它幻觉数值。
- 输出固定 JSON Schema；模型无法满足时输出 `{}` + “无法确认”字段，**不幻觉**。

### C-1 模板（English）

```text
You are a strict video QC auditor for an AI video-generation platform.
TASK: Given one shot sampled as equidistant frames (indices 0..N-1) plus
deterministic detector outputs, decide visual anomalies.

RULE:
1. Report ONLY what is visible in the provided frames. Do not infer beyond evidence.
2. Classify severity: 0=pass, 1=minor, 2=blocker.
3. If undecidable from the frames (e.g. motion between two frames is unknown), set
   "undecidable": true instead of guessing.
4. Outputs must be valid JSON, EXACTLY this schema:
{"shot_id":"...","frames_checked":[0,2,4],"verdict":"pass|review|reject",
 "anomalies":[{"type":"morphing|subject_loss|subject_duplication|limb_malformation|
 flashing|black_frame|frozen|duplicate_frames|cut_break|noise_burst|jitter|
 color_bleed|text_defect|other",
 "frames":"2-5","severity":0|1|2,
 "evidence":"what you see, one sentence","rect":[x0,y0,x1,y1] or null}],
 "deterministic_cues_reviewed":["frozen 0.8s","black 0.4s"]}

DETECTORS (already computed, treat as hints, verify visually):
{black:[[0.0,0.42]], frozen:[[1.2,0.3]], flicker_idx:0.28, dup:[[0.2,0.6]]}

FRAMES: (attach image list)
```

## D. 成本分层与分工（重点：能写进 Python + ffmpeg 的架构）

```
┌─ L0  ffmpeg 原生探针（本地, CPU, ~0.1–0.5× 片长）
│    blackdetect/silencedetect/freezedetect/ffprobe PTS/CUBA      → 整片跑（最便宜）
├─ L1  numpy/opencv 统计（L0 之上, 1–3× 实时）
│    亮度/黑/白/频闪/噪声/重复帧/落帧/切点/抖动候选                  → 整片跑
├─ L2  轻量模型（GPU 可选, 分钟级）
│    ・光流（RAFT/Farneback）→ 运动能量/静止判定     仅对 L1 告警镜头
│    ・DINO/CLIP 特征轨迹 → subject/bg 一致性（VBench 公式照搬）
│    ・DOVER-Mobile/Q-Align → 每镜头 MOS（质分存curve供阈值）
│    （T2VQA/FAST-VQA/DOVER 大模型版本可选作离线评测批量）
├─ L3  VLM 语义审（QLM 调用, $0.001~0.05/镜头）
│    morph/主体消失/肢体/残影/边缘/构图语义 → 仅 L1/L2 异常镜头 + 3%~5% 随机抽样
└─ L4  人工：P0 否决级 + 客户区分
```

**成本级顺序（一个 30 镜、每镜 5s 的成片）：**
| 层 | 单片成本量级 | 说明 |
|---|---|---|
| L0 ffmpeg | CPU 0.1–3 秒 | 与“现在已有的黑帧/静音”合流 |
| L1 numpy | <15 秒 CPU | 成片 1280p 抽 240p 灰度，内存 <200MB |
| L2 简模 | GPU 0.5–2 分钟（或抽帧降采样到 CPU 分钟级） | 只跑告警镜头；MOSA 每次必跑（便宜） |
| L3 VLM | 0.02–0.5 美元（GPT-4o-mini / Qwen2.5-VL-7B → 30–100 镜次） | 只跑 L1/L2 命中的 ~10–20% 镜头 + 抽检 |
| L4 人工 | 视命中率 | 目标 <2% 由审查链直接出 | 

**必须 VLM 的一档（确定性永远做不了）：** 变形、肢体/五官语义、主体语义消失、构图语义是否合理“断”、跨镜头语义连贯（VLM-2 才可靠）。**凡有“语义”的都别硬算**。

## E. 给平台的直接落地建议（对照现状）
- 已有 VLM 变体/黑帧/静音/复用红线等等之上，**先补 L1 的“频率+噪声+重复+落帧+切帧”六联本地探测器**（B 节代码直接可用）。
- **统一“镜头级”粒度**：request 每一镜（分镜文件）单独的结果 JSON，成片级再做聚合规则（如 ≥2 个 P1 重出）。
- **阈值入库成配置**：慢域（黑、白、静）按 VBuild 的 scale 规则缩放；大噪/闪频按内容域样本集标定。
- **VLM 审查全部走 C 节 JSON Schema**，把现在的自由文本改成结构化，方便回溯与人工复核。
- 分层次序是**大部分团队**成熟模式（EvalA/RDover/Q-Align 均为独立组件），可渐进引入 L2 的 DOVER-Mobile 兜底质量分（无需序列）。
