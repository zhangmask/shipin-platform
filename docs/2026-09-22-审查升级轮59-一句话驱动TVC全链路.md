**用 AGNES 视频生成实测「几句话驱动做 TVC/宣传视频」**——真实走
intake→text→confirm→generate(真 AGNES 图+视频)→assemble→finalize,
把断点逐个修掉,并对终审暴露的质量 finding 做门的校准(误报修复)。

## 实测链路(tvc-07431,真实 AGNES,竖版 720x1280)

- text(真 LLM 66s)→ confirm → generate(真生图+真视频 4 镜,~25min)
  → assemble(stitch/字幕/声床/归一化)→ **final.mp4 3.35MB 真出**。
- 终审 fix 的 finding 全部是**内容质量类**(S03 景别/Logo 不符、
  S01 光线方向反、旁白 ASR)——即用户说的「做不出好视频」正是
  内容层,不是链路层。本轮修链路断点 + 门的误报;内容生成质量
  (景别/光线遵循)留作下一轮迭代项。

## 断点1:brief 两个「可为空」维度 key 缺失即 STOP(api.py)

一句话只带核心维度,`_review_brief` 对 reference_materials/
special_requirements 是「key 不在即 critical」→ text 阶段第一轮
STOP,**用户一句话永远进不了流程**。修:pipeline_text 入口按
BRIEF_DIMENSIONS 文档语义补默认值(空串/15s)。实测:text 全过。

## 断点2:video_prompt 380 字上限无机械修复(engine.py)

LLM 模板生成的 prompt 系统性超限(实测 406/386/388),
WORD_COUNT_EXCEEDED 只报 critical 交回 LLM 重写 → 每轮又超 →
3 轮 stall,generate 在文本阶段卡死。修:`_fix_prompt_word_count`
确定性裁剪(句边界优先→空格边界→硬截),真实数据收敛
(406→321 PASS)。

## 断点3:云端生图白名单漏 API 主机(generate_assets.py)

`_IMG_HOSTS` 只有 cos 产物域——/v1/images 返回的产物 URL 落在
apihub.agnes-ai.com,白名单拒之 → **云端生图 100% 断**(换本地
后端修好的镜像病:云端路径从没跑通)。修:补主机。实测:S01-S04
真视频出。

## 断点4:字幕折行预算画幅错位(pipeline_runner.py)

manifest 无 canvas_w 时回退横屏 1280 折行,竖版 720x1280 项目
可用宽只有 446px → 12 字 slogan(598px)必被 §10.6 打死,
assemble 到字幕 100% 卡死。修:宽度取实际 media(ffprobe)画幅。
实测:最宽行 61.0% 压线内,final.mp4 出。

## 质量门校准1:ASR 段归属改中点(hard_gates.py)

旧逻辑「起止与窗有任意重叠即整段计入」把落版词混进前邻窗
(S04 [11.87,13.91] 抓到 14-17s 落版句,sim 0.09 误报)。
修:段中点在窗内才归属。实测:S05 落版 sim 0.09→0.917。

## 质量门校准2:短句 ASR 固有误差(hard_gates.py)

真 ASR 实测:whisper base 对 4 字金句误差达 0.2(「醇香散疲惫」
→「純鄉散皮背」0.20、「按键心意达」→「按鍵新一打」0.40)——
长句阈值 0.45 对短句必误报。修:≤8 字短句专用阈值
(crit 0.12/warn 0.35),阈值随 sims 落账可复核。实测:该项目
内容门收敛 ok(仅 1 条 DRIFT warning)。
